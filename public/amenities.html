In-room features

Bed, bath, minibar, workspace and views that come with the room you book. See them in the 3D room tour.

Shared hotel facilities

The pool, gym, sauna, restaurant, casino lounge and game hall below, shared by all hotel guests with the access rules shown on each card. The fountain plaza, theater and ballroom host scheduled events and can be booked.
